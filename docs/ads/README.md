# Smiles — рекламная кампания «Попади, если сможешь»

## Идея

Smiles продаёт одно ощущение: **выстрел, который попал**. Взрыв, «Бабах!»,
цифра урона, замедление на решающем ударе. Вся реклама показывает настоящий
геймплей (не постановочный арт) и бьёт в три мысли:

1. **Это в Telegram** — ничего не скачивать, открыл в чате и играешь.
2. **Это смешно и красиво** — смайлики, рогатка, трос, 18 видов оружия.
3. **Это с друзьями** — вызов на дуэль из любого чата, турнир недели.

Слоган: **«Попади, если сможешь»** / **«Hit it if you can»**.

## Материалы

| Файл | Формат | Где использовать |
|---|---|---|
| `ru-weapons.mp4`, `en-weapons.mp4` | 9:16, ~17 с | TikTok, Reels, Shorts, сторис каналов |
| `ru-decisive.mp4`, `en-decisive.mp4` | 9:16, ~8 с | короткий хук, превью в постах, Telegram Ads с видео |
| `ru-endcard.png`, `en-endcard.png` | 1080×1920 | финальный кадр, обложка ролика |
| `banners/*` | 1080×1920, 1080×1080, 1280×720 | посты в каналах, сторис, обложки |
| `keyart/*` | 9:16 | постер, шапка канала, закреп |
| `../store/ru`, `../store/en` | 1080×1920 | каталоги мини-приложений |

Ролики собираются из настоящего боя: `tools/ads/record_ad.mjs` (покадровая
запись) → `tools/ads/cut.mjs` (нарезка, подписи, финальная плашка).

## Каналы и бюджет на старт (пример на 2 недели)

| Канал | Что запускать | Доля |
|---|---|---|
| Посевы в Telegram-каналах (игры, мемы, IT-юмор) | пост с роликом `decisive` + кнопка в бота | 45% |
| Telegram Ads | текстовые объявления ниже, ведут на @Fatalgame | 25% |
| TikTok / Reels / Shorts (органика) | ролики `weapons`, 1 в день, свои клипы из игры | 0 ₽, время |
| Каталоги мини-приложений | скриншоты и тексты из `docs/store` | 0 ₽ |
| Турнир недели | анонс в своём канале и в постах-посевах каждую неделю | 0 ₽ |
| Резерв на лучшее | доливаем в посев/объявление с лучшей ценой игрока | 30% |

Главная метрика — **цена игрока, сыгравшего первый бой** (в админке: воронка
«выстрелил» → «прошёл обучение» → «победил»). Вторая — возврат на 1-й и 7-й
день (там же, «возврат новичков»). Посев, где цена игрока выше средней вдвое,
больше не покупаем.

- кнопка «В сторис» после победы (карточка + ссылка-приглашение);
- «Клип» лучшего выстрела — для TikTok/Reels без монтажа;

- рефералка: по ссылке друга обоим коробка со скином;
- «Турнир недели» каждую субботу;
- английский язык по языку Telegram.
