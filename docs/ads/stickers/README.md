## Как загрузить

1. Открой в Telegram бота @Stickers, команда `/newpack`.
2. Тип — «Статичные» (Static), название пака — «Smiles».
3. Шли файлы по одному **как файл** (не как фото), после каждого — эмодзи из таблицы.
4. `/publish`, иконку пака пропусти (`/skip`), короткое имя — например `smiles_fatalgame`.
5. Ссылка на пак: `https://t.me/addstickers/smiles_fatalgame` — её в описание бота,
   в посты и в закреп канала. Стикеры разлетаются по чатам — бесплатная реклама.
